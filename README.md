# FFT_Music
Uses fast fourier transform algorithm to analyze your microphone audio to determine to musical notes.

Click [here](https://github.com/Izz4c/FFT_Music/releases/latest/) to find the latest release for Windows(easier than compiling yourself)

<img width="427" height="424" alt="image" src="https://github.com/user-attachments/assets/4a310d63-fcd5-42ae-af14-8be2d0dd1d80" />

1) Generate Notes
2) Enter sampling rate (default 44.1k) 
3) Enter note name to map to the first frequency (default A4-440Hz)
4) Press enter while playing/humming the tone to your microphone (multiple times if you wish)
5) Press Q to stop

There are other features in this program too, like converting notes from one scale to another (Harmonize option), generating scales with a root note, and displaying all the frequencies audible to the mic.
